# Presentación de Festholic

Diseñé la interfaz de Festholic con negro, morado y rosado, tipografía Inter local, títulos claros, formularios legibles y un footer compacto. Organicé los estilos con variables y mixins SASS. La licencia de la fuente se incluye en public/fonts.

Los afiches se presentan con sus colores originales. No aplico filtros, tintes ni capas superpuestas sobre las imágenes. Si falta un afiche o falla su carga, presento el nombre del evento como alternativa.

Preparé tres eventos de ejemplo mediante un script SQL para demostrar el catálogo, el CRUD y la compra. Conservo sus fechas, lugares y afiches de referencia; el aforo configurado es un valor académico para las pruebas, no una capacidad oficial.

Toda la aplicación mantiene el flujo Angular → Spring Boot → MySQL. La API externa se utilizó únicamente para obtener los datos iniciales, no como una dependencia del catálogo en ejecución.

Verifiqué el catálogo, la cuenta, los formularios, los afiches, el selector de cantidad, la compra y el footer en escritorio y móvil. Los resultados y las capturas están en esta carpeta.
